# Future Roadmap

See the root [ROADMAP.md](../ROADMAP.md) for the active development schedule.

## Long-term Vision

### 1. Semantic Memory (Knowledge Graph)
We plan to migrate from simple structural fingerprinting to deep semantic memory using Neo4j. Agentix will understand cross-domain relationships autonomously.

### 2. Self-Learning Engines
The engines themselves will begin generating synthetic datasets to "dream" and practice execution paths while idle.

### 3. Enterprise Features
- Multi-tenancy isolation.
- SSML / SAML Auth.
- Auditable execution logs.
