# Security Policy

## Supported Versions

Currently, we provide security updates for the following versions of Agentix:

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| 0.3.x   | :x:                |
| < 0.2   | :x:                |

## Reporting a Vulnerability

Security is a top priority for the Agentix platform, given it handles data science workflows and potential PII processing.

If you discover a security vulnerability within Agentix, please do NOT submit an issue on GitHub. Instead, please send an e-mail to our security team at **security@agentix.ai**. 

### Responsible Disclosure
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We aim to patch critical vulnerabilities within 7 days.
- Please allow us the time to patch the issue before publicly disclosing it.

Thank you for helping keep Agentix safe!
