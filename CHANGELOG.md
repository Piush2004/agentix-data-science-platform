# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.4.0] - 2026-07-06
### Added
- **Strategy Intelligence Engine**: Added Procedural Memory.
- **Strategy Miner**: Identifies recurring patterns from episodic logs.
- **Strategy Learner**: Mathematically updates success/confidence bounds.
- **Agentix Brain**: Re-architected cognitive loop to integrate `Strategy Recall` and `Strategy Learning`.

## [0.3.0] - 2026-07-01
### Added
- **Episodic Memory System**: Deterministic fingerprinting and retrieval of past executions.
- **Deliberation Engine**: System 2 reasoning introduced before workflow generation.

## [0.2.0] - 2026-06-15
### Added
- Agent Orchestration Layer.
- Next.js Dashboard v2.

## [0.1.0] - 2026-05-01
### Added
- Initial Open Source Release.
- FastAPI backend foundation.
