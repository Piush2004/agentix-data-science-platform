# Roadmap

The development of Agentix is guided by the following roadmap.

### Version 0.1: Foundation (Completed)
- [x] Next.js Dashboard UI
- [x] FastAPI Core routing
- [x] Database schema & PostgreSQL integration
- [x] Dataset Upload pipeline

### Version 0.2: Brain (Completed)
- [x] 8-stage Cognitive Loop implementation
- [x] Deliberation Engine (System 2 internal reasoning)
- [x] Integration with specialized agents

### Version 0.3: Memory (Completed)
- [x] Episodic Memory framework
- [x] Deterministic Dataset Fingerprinting
- [x] Similarity Engine for past executions

### Version 0.4: Strategy Intelligence (Completed)
- [x] Offline Strategy Mining algorithms
- [x] Strategy Builder and Versioning
- [x] Strategy Learning & Evolution metrics

### Version 0.5: Knowledge Graph (Planned)
- [ ] Transition from structural fingerprinting to semantic mapping
- [ ] Integration with Neo4j
- [ ] Cross-domain entity resolution

### Version 0.6: Enterprise (Planned)
- [ ] Role-Based Access Control (RBAC)
- [ ] Multi-tenant data isolation
- [ ] SSO / SAML integration
- [ ] Audit Logging

### Version 1.0: Stable Release (TBD)
- [ ] Production hardening
- [ ] Comprehensive E2E Test Suite
- [ ] Cloud Marketplace Images (AWS AMI, Azure)
